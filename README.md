# Рефлексия кофе — концепт сайта

Независимый демонстрационный макет веб-студии. Это не официальный сайт организации и не утверждение о партнерстве с ней.

- Категория: Кофейня; кафе
- Адрес по Яндекс Картам: ул. Гоголя, 1, Екатеринбург
- Публичная карточка: https://yandex.com/maps/org/refleksiya_kofe/142157806614/
- Фотоисточник для визуального исследования: https://yandex.com/maps/org/reflection_coffee/142157806614/gallery/
- Проверка собственным доменом: на 10.10.2026 отдельный официальный сайт не найден в карточке и публичном поиске; каталоги и соцсети не считались собственным доменом.
- Главное изображение создано специально для этого концепта по публичным фото фасада или точки. Исходные пользовательские фотографии и логотипы не включены.
- Отзывы и карта загружаются официальными виджетами Яндекс Карт; текст отзывов не копируется вручную.

## Разработка

**npm ci** устанавливает зависимости из lock-файла. **npm run dev** запускает локальный просмотр, **npm run build** проверяет TypeScript и собирает сайт в **dist**.

GitHub Actions собирает проект и публикует его в GitHub Pages после отправки изменений в основную ветку.
